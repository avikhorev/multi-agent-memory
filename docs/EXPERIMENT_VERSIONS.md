# Варианты памяти и версии экспериментов

Этот справочник отвечает на вопрос: **какой именно код, на каких сценариях и с какими настройками дал опубликованное число?** Он дополняет [историю решений D1–D44](DECISION_INDEX.md), но не заменяет её.

## Основной прогон (до заморозки результатов)

| Имя в данных | Реализация | Режим и источник фактов | Где результат |
|---|---|---|---|
| `ours` | [`src/mam/systems/ours.py`](../src/mam/systems/ours.py) | Живой `eval`, `extractor="llm"`; 21 сценарий A × 2 повтора | [`main/units/`](../results/live/main/units/), [124/156 (E2)](EVIDENCE.md#e2) |
| `full_history`, `sliding_window`, `rolling_summary`, `shared_rag_bm25` | [`src/mam/systems/`](../src/mam/systems/) | Те же 21 сценарий и повторы; `rolling_summary` обновляется моделью | [Основные таблицы](../results/live/main/tables.md) |
| `ours@cache` | `Ours`, [`memory_eval.py`](../src/mam/memory_eval.py) | Без агента, 210 сценариев `eval`; сохранённое извлечение | [778/780 (E1)](EVIDENCE.md#e1) |
| `ours@oracle`, `ours@rules` | Та же `Ours` | Без агента; эталонные факты генератора / извлечение по правилам | [`memory_level/eval/`](../results/memory_level/eval/) |
| `rolling_summary@cache`, `rolling_summary@rules` | [`summary.py`](../src/mam/systems/summary.py) | Без агента; кеш модели / правила | [`memory_level/eval/`](../results/memory_level/eval/) |

Суффикс `@cache` — **способ извлечения на уровне памяти**, не новая версия `ours` и не повтор живого запуска. Суффиксы `-no_validity`, `-no_scopes`, `-no_trust`, `-no_pinned_constraints` выключают по одному механизму `ours` в абляциях. `@oracle` использует знания генератора, которых нет у живого агента. Эти режимы **нельзя** объединять в один общий итог эффективности.

## Как безопасно добавлять новую строку

1. Зафиксировать **имя в JSON-манифесте**, реализацию/коммит, способ извлечения, сценарии, число повторов, модель и правила оценки.
2. Указать, что число означает: `все проверки`, `только факторные` или `контекст без агента`; приложить числитель и знаменатель.
3. Отметить статус «основной», «post hoc» или «не выполнялось». Новый запуск **не меняет** статус исторических результатов.
4. Сослаться на исходные `units/`, `*.jsonl` или отдельный `criteria.md` и дополнить [карту доказательств](EVIDENCE.md), если результат попал в обзор.

Для новой реализации интерфейса памяти см. [руководство по расширению](EXTENDING.md). Для сравнимости результатов — [матрицу условий](PROBLEM.md#сравнимость-систем).
