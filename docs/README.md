## Поддержка документации

`make docs-check` работает без LLM: проверяет локальные ссылки и якоря, привязанные к коммитам ссылки на строки кода, упоминаемые цели `make`, замороженные численные итоги и [SHA-256 исходных артефактов](frozen_artifacts.json). Та же команда запускается в CI. Для **пересчёта**, который перезаписывает `results/`, используйте [отдельную рабочую копию](RUNBOOK.md#безопасный-пересчёт-в-отдельной-рабочей-копии).

**Чек-лист при изменениях:**

- Поменялся [`score_action`](../src/mam/scoring.py#L95), [`score_context`](../src/mam/scoring.py#L45) или отбор точек — обновить [определения метрик](PROBLEM.md#как-читать-знаменатели), [спецификацию](SCENARIO_FORMAT.md) и проверить числа в [EVIDENCE](EVIDENCE.md).
- Поменялся сценарий или генератор — проверить `data/*/manifest.json`, обновить описание сплитов и **не** перезаписывать старые эталоны молча.
- Добавился вариант памяти — обновить [реестр версий](EXPERIMENT_VERSIONS.md), проверить сопоставимость и статус *post hoc*.
- Поменялись сырые измерения — зафиксировать причину и исходные файлы **до** замены хешей в [`frozen_artifacts.json`](frozen_artifacts.json); новые результаты не выдавать за прежний замороженный прогон.

## Как устроены доказательства

- **До заморозки:** проектирование, пилот, `dev` и базовые правила. Тег `benchmark-frozen` фиксирует постановку основных экспериментов.
- **Основные результаты:** `eval`, отдельный `holdout` и живой прогон варианта A; см. разделы 5–9 отчёта.
- **После заморозки (*post hoc*):** дополнительные проверки подачи, новые версии памяти, новые данные и внешние системы; разделы 11–15 отчёта. Их результаты полезны, но не являются заранее запланированной проверкой основной гипотезы.

Файлы `results/**/tables.md` и `results/post_hoc/` содержат таблицы и отчёты отдельных прогонов. Это **результаты измерений**, а не инструкции по использованию проекта. Команды для работы с ними приведены в [руководстве](RUNBOOK.md).

## Термины

| Термин | Значение |
|---|---|
| Сценарий | Цепочка сессий с заданными событиями и эталоном |
| Контрольная точка | Вопрос или действие, для которого известно ожидаемое поведение |
| `ours` | Исходная структурированная память, участвовавшая в основном сравнении |
| `ours2`–`ours4` | Экспериментальные варианты, созданные после заморозки |
| Уровень памяти | Проверка собранного контекста без вызовов агентов |
| Живой слой | Проверка поведения агентов с вызовами модели |
| `refusal` | Отказ провайдера; учитывается отдельно от ошибок памяти и агента |

## Subdirectories & Boundaries

- [`demo/`](demo/README.md) — статический проигрыватель сохранённых трасс (`index.html`, `demo.js`, `data.js`, `style.css`); `data.js` генерируется скриптом `scripts/build_visual_demo.py`.
- [`frozen_artifacts.json`](frozen_artifacts.json) — манифест (схема 1), который читает `scripts/check_frozen_artifacts.py` (`MANIFEST`); хранит только число файлов и SHA-256 по шести glob-шаблонам.
- `img/` — SVG-схемы для документов (`visual-story.svg`, `memory-flow.svg`, `conflict-resolution.svg` и др.); исходного кода нет, собственного контракта нет.

## Global Invariants

- Документы описывают замороженный эксперимент. Хеши исходных артефактов хранятся в [`frozen_artifacts.json`](frozen_artifacts.json) (`data/eval/*.json`, `holdout/*.json`, `results/extraction/eval/cache.jsonl`, `results/live/main/units/*.json`, `results/live/main/traces/*.jsonl`, `results/memory_level/eval/*.jsonl`); численные итоги (`EXPECTED_MEMORY`, `EXPECTED_LIVE`, 780 / 156 / 42) заданы в `scripts/evidence_summary.py`. Оба проверяются `make docs-check`.
- Локальные ссылки и якоря, ссылки на строки кода, привязанные к коммитам, и упоминаемые цели `make` проверяются скриптом `scripts/check_docs.py` только для корневых `*.md` и `docs/**/*.md` (README в `src/`, `scripts/`, `external/` им не проверяются). Привязанные ссылки требуют коммитов в локальной истории git (CI использует `fetch-depth: 0`, `.github/workflows/docs.yml`).
- `docs/demo/data.js` генерируется, а не правится вручную.

## Global Side Effects

- Каталог документации не изменяет `data/` и `results/`; `make docs-check` работает без LLM. `make visual-demo` (`scripts/build_visual_demo.py` без `--check`) перезаписывает `docs/demo/data.js`.
- Пересчёт, перезаписывающий `results/`, выполняется только по [отдельной инструкции](RUNBOOK.md#безопасный-пересчёт-в-отдельной-рабочей-копии).
